# Phase 1 — Foundation

## Included in the first increment

- .NET solution boundaries.
- Secure web host defaults.
- HR and file-storage abstractions.
- First organizational domain rule and test.
- Continuous integration build and test.
- Initial architecture decisions.

## Pending proofs of concept

- Oracle provider compatibility with .NET 10, EF Core, Identity, migrations, and optimistic concurrency.
- Connectivity to a non-production Oracle schema.
- File-server staging/commit and streaming behavior.
- Centralized exception handling and structured logging implementation.

No production connection strings, credentials, or paths are stored in this repository.
